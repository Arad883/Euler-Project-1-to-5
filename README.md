# Euler-Project-1-to-5
Solving Project Euler Problems 1 through 5 in Julia

▶️ Usage

Make sure Julia is installed, then run any file:

```bash
julia euler1.jl
```

✅ Answers

Problem Answer

2 — Even Fibonacci numbers 4613732
3 — Largest prime factor 6857
4 — Largest palindrome product 906609
5 — Smallest multiple 232792560

🧠 Notes
